# Sistem Monitoring Perubahan Sosial dan Emosional Siswa SD

## Deskripsi

Sistem ini merupakan sistem informasi berbasis web yang dirancang untuk membantu sekolah dalam melakukan monitoring perubahan sosial dan emosional siswa sekolah dasar serta memantau minat belajar siswa.

Sistem digunakan untuk mencatat hasil pengamatan guru secara berkala sehingga perkembangan siswa dapat terdokumentasi dengan lebih terstruktur dan dapat digunakan sebagai bahan pemantauan oleh pihak sekolah.

Sistem ini tidak digunakan untuk melakukan diagnosis psikologis atau menentukan kondisi kesehatan mental siswa.

## Judul Proyek

**Rancang Bangun Sistem Monitoring Perubahan Sosial dan Emosional Siswa Sekolah Dasar Berbasis Web untuk Mendukung Pemantauan Minat Belajar**

## Tujuan

Sistem ini bertujuan untuk:

1. Membantu guru mencatat perkembangan sosial siswa.
2. Membantu guru mencatat perkembangan emosional siswa.
3. Membantu guru memantau minat belajar siswa.
4. Menyimpan riwayat perkembangan siswa secara terstruktur.
5. Membantu guru melihat perubahan perkembangan siswa dari waktu ke waktu.
6. Membantu sekolah memiliki dokumentasi perkembangan siswa yang lebih terorganisir.

## Pengguna Sistem

Sistem memiliki tiga jenis pengguna:

### 1. Admin

Admin bertugas untuk:

- Mengelola data pengguna.
- Mengelola data siswa.
- Mengelola data kelas.
- Mengelola data guru.
- Mengelola hak akses pengguna.

### 2. Guru

Guru bertugas untuk:

- Melihat data siswa.
- Melakukan pencatatan perkembangan siswa.
- Mengisi monitoring sosial siswa.
- Mengisi monitoring emosional siswa.
- Mengisi monitoring minat belajar siswa.
- Menambahkan catatan hasil pengamatan.
- Melihat riwayat perkembangan siswa.
- Membandingkan perkembangan siswa antarperiode.

### 3. Siswa

Siswa dapat:

- Login ke sistem.
- Melihat informasi perkembangan dirinya.
- Melihat riwayat hasil monitoring yang dapat diakses oleh siswa.

## Fitur Utama

Fitur utama yang direncanakan dalam sistem:

- Login dan autentikasi pengguna.
- Manajemen data pengguna.
- Manajemen data siswa.
- Manajemen data kelas.
- Monitoring perkembangan sosial.
- Monitoring perkembangan emosional.
- Monitoring minat belajar.
- Catatan hasil pengamatan guru.
- Riwayat perkembangan siswa.
- Perbandingan perkembangan antarperiode.
- Pencarian dan filter data.
- Informasi perkembangan siswa.

## Indikator Monitoring

Monitoring dilakukan berdasarkan beberapa indikator.

### Perkembangan Sosial

Indikator yang digunakan antara lain:

- Interaksi dengan teman.
- Kerja sama.
- Komunikasi.
- Partisipasi dalam kegiatan.
- Kesediaan membantu teman.

### Perkembangan Emosional

Indikator yang digunakan antara lain:

- Kemampuan mengenali emosi.
- Kemampuan mengendalikan respons.
- Kemampuan menghadapi perubahan.
- Kemampuan meminta bantuan.
- Konsistensi perilaku.

### Minat Belajar

Indikator yang digunakan antara lain:

- Ketertarikan terhadap pembelajaran.
- Keaktifan mengikuti pembelajaran.
- Penyelesaian tugas.
- Rasa ingin tahu.
- Ketekunan dalam belajar.

## Batasan Sistem

Sistem ini memiliki beberapa batasan:

- Sistem hanya digunakan untuk monitoring dan dokumentasi perkembangan siswa.
- Sistem tidak melakukan diagnosis psikologis.
- Sistem tidak menentukan apakah siswa mengalami gangguan psikologis.
- Sistem tidak menggunakan metode SAW.
- Sistem tidak menggunakan metode TOPSIS.
- Sistem tidak menggunakan kecerdasan buatan sebagai fitur sistem.
- Sistem tidak menggantikan peran guru dalam melakukan pengamatan dan pendampingan siswa.
